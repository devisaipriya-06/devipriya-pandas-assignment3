# Pandas for AI/ML – Conceptual & Technical Assessment

## 📌 Overview

This repository contains my **Pandas for AI/ML – Conceptual & Technical Assessment** for Module 3.

The assignment focuses on using Pandas and NumPy for **data manipulation, analysis, cleaning, statistical analysis, and practical AI/ML applications**.

## 📚 Topics Covered

The assignment is divided into four sections:

### Section A – Output Prediction
This section focuses on predicting and understanding the output of Pandas and NumPy operations.

Topics include:
- NumPy array operations
- Pandas Series
- Boolean filtering
- Descriptive statistics
- Mean, median, and maximum
- Group-wise analysis using `groupby()`
- Correlation analysis
- Positive and negative correlation

### Section B – Code Correction
This section focuses on identifying and correcting common Pandas coding mistakes.

Topics include:
- Reading CSV files
- Handling CSV headers
- Sorting DataFrames
- Finding highest values
- Handling missing values
- Replacing missing values using `fillna()`
- Correlation calculation

### Section C – Edge Cases
This section covers situations where careful handling of data and array structures is required.

Topics include:
- NumPy broadcasting
- Array shapes
- CSV parsing
- Quoted values
- Missing values
- Date conversion
- Data type handling

### Section D – Scenario-Based Problems
This section applies Pandas concepts to practical data analysis scenarios and AI/ML-related problems.
